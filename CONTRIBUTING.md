# Contributing to Plasmie

Thanks for wanting to help.

## What's welcome

- **Bug reports and ideas:** open an issue. Copy diagnostics from the Plasmie window
  (Maintain › Copy diagnostics) if something's broken. It leaves out your notes and passwords.
- **Questions** about using the code, the name or the mascot: open an issue and ask.

## Code changes

I'm not accepting pull requests yet. Plasmie is offered under the GPL and also sold as a
signed build, and keeping every line under one owner keeps that simple. If you have a fix,
open an issue describing it and I'll work it in.

This may change later, with a short contributor agreement.
