# Plasmie name and mascot

Plasmie's code is licensed under the GNU General Public License v3 (see `LICENSE`). That
license covers the code. It does not give permission to use the name "Plasmie" or the pink
blob mascot as branding.

## What's fine

- Building, changing and sharing the code under the GPL.
- Saying plainly what your version is based on, for example "based on Plasmie".
- Talking about, reviewing or writing tutorials for Plasmie.

## What needs permission

If you distribute your own build or a fork, give it a different name, app icon, bundle ID
and mascot, so nobody mistakes it for the official Plasmie. Don't sell or publish anything
as "Plasmie", or with the blob mascot, without written permission.

The official builds are the ones published by the Plasmie project.

Questions: open an issue in this repository.
