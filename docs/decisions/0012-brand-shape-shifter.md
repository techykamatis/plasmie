# 0012 · Brand: Plasmie, a soft blob whose shape is the status

- **Status:** Accepted · 2026-10-03
- **Area:** Design

## Context
The owner asked for a cute identity, a better name and a mascot, referencing OpenAI's
dots (a customisable blobby agent crew), Meta Muse's mascot Jolly, and xAI's Grok Bot /
Groklet. Audience: the owner alone (confirmed). Two decision rounds were run; the first
had no mascot visible ("where's the mascot?"), so round two drew each one.

## Decision
- **Plasmie**: a soft blob, played straight at full craft, given one mechanism the
  category doesn't have. In the owner's words, *"a blob can take any shape or form"*:
  Plasmie **shape-shifts into each pipeline state** (bowl catching source dots = ingest,
  dumpling = summarise, box = promote, lightbulb = Ask, raised hand = held, puddle =
  failing, hourglass = busy, flat mochi = quiet, curled ball = off, star = success).
- The app, bundle and executable are named Plasmie; "Plasmie" survives as a descriptor.
- Plasmie's mood must reflect the real pipeline state; a dead ingest never looks happy.

## Alternatives seen and passed over
Library circulation desk ("Dewey"), Waggle the honeybee, Stacky (HyperCard card),
Kertas (papercut bird), Nightjar (instrument owl), arcade sprite, mixtape j-card,
Shibuya obi sleeve. Names considered: Mochi, Putty.
