# 0014 · Palette: brain pink with a berry face; no literal brain cue

- **Status:** Accepted · 2026-10-03
- **Area:** Design

## Decision
- Body `#F49AB2` (dark `#F7A8BE`), belly sheen `#FBC9D6` (a soft ellipse clipped to the
  body), ink/face `#3A1430`, blush `#E8668A`, off `#C9B9C0`. Owner's direction: "a
  somewhat pink colour, like the common colour to represent brain". Replaced the first
  lavender/indigo palette.
- Semantic accents used sparingly: sparkle `#FFC94A` (success, held, Ask, sand), sweat
  `#6EC5F0` (failing). Source dots are the only multicolour moment; Slack became
  aubergine so it doesn't vanish into the pink body.
- App chrome stays native (system font, semantic colours); the brand lives in Plasmie,
  the icon and the menu-bar glyph (a template image that follows light/dark menu bars).

## Alternatives rejected
Brain folds on the crown, two lobes with a parting, folds plus a gloss highlight: shown
side by side; the owner said "forget this", so Plasmie stays a plain blob.
