# 0016 · Palette: brain pink with a berry face; no literal brain cue

- **Status:** Accepted
- **Area:** Design

## Context
The owner's direction for colour: "a somewhat pink colour, like the common colour to
represent brain". The mascot carries the brand; the rest of the app should feel like a
native Mac app.

## Decision
- **Body** `#F49AB2` (dark `#F7A8BE`), **belly sheen** `#FBC9D6` (a soft ellipse clipped to
  the body), **ink/face** `#3A1430`, **blush** `#E8668A`, **off** `#C9B9C0`.
- **Semantic accents, used sparingly:** sparkle `#FFC94A` (success, held, Ask, sand), sweat
  `#6EC5F0` (failing). Source dots are the only multicolour moment; Slack's dot is aubergine
  so it doesn't vanish into the pink body.
- **App chrome stays native** (system font, semantic colours). The brand lives in the
  mascot, the icon and the menu-bar glyph, a template image that follows light and dark
  menu bars.

## Alternatives rejected
Brain folds on the crown, two lobes with a parting, folds plus a gloss highlight. Shown side
by side, the owner turned them all down ("forget this"), so the mascot stays a plain blob.
