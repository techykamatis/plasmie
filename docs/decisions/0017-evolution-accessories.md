# 0017 · Evolution is shown as accessories

- **Status:** Accepted · 2026-10-03
- **Area:** Design

## Decision
Each stage adds one accessory drawn on the crown of whatever shape Plasmie is in:
eggshell (Hatchling), leaf sprout (Sprout), round glasses (Thinker), mortarboard
(Scholar), wizard hat with stars (Sage), crown (Elder Brain). Only the current stage's
accessory is worn; none on the 18 pt menu-bar glyph. The Trophies window shows past
stages in colour, the current one ringed in blush, and future ones dimmed.
