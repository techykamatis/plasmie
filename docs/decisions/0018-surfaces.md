# 0016 · Plasmie is the focal point of each surface

- **Status:** Accepted · 2026-10-03
- **Area:** Design, layout

## Decision
- Panel: a 104 pt Plasmie on a soft pink stage, name, "<Stage> · N of M trophies", status
  pill; under it the "Plasmie remembers" fun-fact card.
- Ask overlay: Plasmie in a leading column beside the field, 88 pt, springing down to
  56 pt when an answer arrives; answer text aligned to the field.
- Settings: one scrolling page, resizable, dirty-aware Save/Close. Trophies window:
  header, evolution strip, shelf.
- Status vocabulary is shared ("All flowing / Needs review / Needs attention", connector
  verdicts Flowing / Quiet / Failed last run / Not working / Not set up / Off), every
  verdict with a symbol, never colour alone.
- Freshness bars are labelled with each source's usual cadence (the owner read the
  unlabelled 96 h bar as a progress bar).
