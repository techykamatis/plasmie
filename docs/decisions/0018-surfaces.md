# 0018 · The mascot is the focal point of each surface

- **Status:** Accepted
- **Area:** Design, layout

## Context
Plasmie has a few small surfaces: the panel, the Ask overlay, Settings and the Trophies
window. Each should lead with the mascot and speak the same status language.

## Decision
- **Panel:** a 104 pt mascot on a soft pink stage, the name, "<Stage> · N of M trophies" and
  a status pill; under it the "Plasmie remembers" fun-fact card.
- **Ask overlay:** the mascot in a leading column beside the field at 88 pt, springing down
  to 56 pt when an answer arrives; answer text aligned to the field.
- **Settings:** one scrolling page, resizable, with Save and Close that know about unsaved
  changes. **Trophies window:** header, evolution strip, shelf.
- **One status vocabulary:** "All flowing / Needs review / Needs attention"; connector
  verdicts Flowing / Quiet / Failed last run / Not working / Not set up / Off. Every verdict
  has a symbol, never colour alone.
- **Freshness bars are labelled** with each source's usual cadence, so a 96 h bar isn't read
  as a progress bar.
