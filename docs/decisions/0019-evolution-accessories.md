# 0019 · Evolution is shown as accessories

- **Status:** Accepted
- **Area:** Design

## Context
The mascot's shape already carries the pipeline status ([0014](0014-brand-plasmie.md)), so
its evolution stage ([0012](0012-achievements.md)) needs a cue that works on every shape.

## Decision
Each stage adds one accessory drawn on the crown of whatever shape the mascot is in:
eggshell (Hatchling), leaf sprout (Sprout), round glasses (Thinker), mortarboard (Scholar),
wizard hat with stars (Sage), crown (Elder Brain). Only the current stage's accessory is
worn, and none on the 18 pt menu-bar glyph. The Trophies window shows past stages in
colour, the current one ringed in blush, and future ones dimmed.

## Consequences
Accessories are the first step toward each person dressing their own plasmie.
