# Tags

Keep tags flat and few. Add to this list before inventing a new one.

- `#decision` — a choice made, with rationale
- `#idea` — a thought to develop later
- `#reference` — imported/external source material
- `#person` — a person note
- `#concept` — an atomic idea you understand
- `#study` — course/book/subject note
- `#someday` — maybe-later, not active
- `#review` — revisit / needs attention

## OKF `type` values in use

Frontmatter `type` (required by OKF) is separate from tags. Current types:
`note`, `concept`, `person`, `project`, `meeting`, `source`, `index`.
